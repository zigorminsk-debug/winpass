# 🔑 WinPass Admin Suite v2.0

**WinPass Admin Suite** — комплексное десктопное приложение с графическим интерфейсом (**PowerShell + WPF Native GUI**) для системных администраторов Windows. Предназначено для оперативного сброса и восстановления забытых паролей пользователей ПК, разблокировки учетных записей, извлечения сохраненных паролей (Wi-Fi, Windows Credential Manager, Password Vault, Winlogon AutoLogon) и офлайн-восстановления доступа через среду **WinPE / Windows RE**.

Работает в **Windows 10 / 11 и Windows Server (2016 / 2019 / 2022)** «из коробки» — без установки сторонних библиотек, компиляторов или рантаймов. Полностью совместимо как с русскими (`ru-RU`), так и с английскими (`en-US`) редакциями Windows (поиск групп и встроенного Администратора выполняется по системным идентификаторам **SID**).

## 🚀 Основные возможности

### 1. 👤 Управление локальными пользователями и сброс паролей
- Просмотр всех локальных учетных записей ПК (логин, полное имя, роль, статус активности, блокировка, дата последнего входа, дата смены пароля, SID).
- Автоматическая поддержка `Get-LocalUser` / `Set-LocalUser` с резервным переключением на **ADSI (`WinNT://`)** и `net.exe user`.
- **Мгновенный сброс пароля** любого локального пользователя:
  - Установка нового пароля с оценкой криптостойкости.
  - **Сброс на пустой пароль (вход без пароля)** с автоматическим снятием флага `ADS_UF_PASSWD_NOTREQD`.
  - Встроенный **криптостойкий генератор временных паролей** (настраиваемая длина 6–32 символа, выбор наборов символов).
  - Настройка параметров при сбросе: *«Срок действия пароля не ограничен»*, *«Потребовать смену пароля при следующем входе»*, *«Разблокировать и включить УЗ»*.
- **Быстрые действия администратора**:
  - Включение / отключение и снятие блокировки (`Unlock`) учетной записи.
  - Добавление или удаление пользователя из группы **Администраторы** по SID `S-1-5-32-544`.
  - **Активация встроенного Администратора (`RID 500`, `S-1-5-21-*-500`)** в один клик.
  - **Создание резервного администратора** (`AdminRecovery`) на случай повреждения основного профиля пользователя.
  - Печать / сохранение **карточки-памятки для пользователя** с новым паролем.

### 2. 📶 Восстановление сохраненных паролей Wi-Fi
- Извлечение всех сохраненных профилей беспроводных сетей WLAN с открытыми паролями (`key=clear`).
- Использует языково-независимый XML-парсинг (`netsh wlan export profile key=clear`) и резервный парсинг `netsh wlan show profile`.
- Копирование ключа в буфер обмена и экспорт всех паролей Wi-Fi в **CSV**.

### 3. 🔐 Диспетчер учетных данных Windows (Credential Manager / Vault) и AutoLogon
- Нативное чтение сохраненных паролей из **Windows Credential Manager** через Win32 API (`CredEnumerateW` в `advapi32.dll`) с декодированием `CredentialBlob`.
- Извлечение веб-паролей из **Windows Password Vault** (`Windows.Security.Credentials.PasswordVault`).
- Чтение и настройка параметров **Winlogon AutoAdminLogon** (`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon` — просмотр сохраненного `DefaultPassword`, включение и очистка автологона).

### 4. 💿 Режим WinPE / WinRE и Офлайн-восстановление (когда в систему невозможно войти)
- Автоматическое определение среды **WinPE / Windows Recovery Environment (`MiniNT`)** и сканирование всех дисков на наличие установленных копий Windows (`\Windows\System32\config\SAM`).
- **Офлайн-инспектор и разблокировщик куста реестра SAM**:
  - Монтирует офлайн-файл `Windows\System32\config\SAM` во временную ветку `HKLM\WINPASS_OFFLINE_SAM`.
  - Разбирает бинарные структуры `F` и `V` учетных записей, отображая `RID`, статус активности, блокировку и счетчик неверных вводов пароля.
  - Позволяет **включить и разблокировать любую учетную запись (включая встроенного Администратора `RID 500`) напрямую в офлайн-файле SAM** путем снятия битов `ACB_DISABLED (0x0001)` и `ACB_AUTOLOCK (0x0010)` по смещению `0x38` с автоматическим созданием резервной копии `SAM.winpass.bak`.
- **Экранный перехват специальных возможностей (`sethc.exe` / `utilman.exe`)**:
  - Автоматическая установка перехвата **5x SHIFT (`sethc.exe`)** или кнопки «Специальные возможности» (`utilman.exe`) с сохранением оригинала в `.winpass.bak`.
  - Позволяет на экране входа обычной Windows открыть консоль `NT AUTHORITY\SYSTEM`, запустить графический интерфейс `WinPass-GUI.ps1` и безопасно изменить пароль без потери зашифрованных данных DPAPI/EFS.
  - Восстановление оригинальных системных файлов в один клик.
- **Сброс забытого ПИН-кода Windows Hello (контейнер `Ngc`)**:
  - Перенос поврежденного контейнера `Windows\ServiceProfiles\LocalService\AppData\Local\Microsoft\Ngc` в резервную копию `Ngc.winpass.bak` для возврата ко входу по обычному паролю.
- **Запись портативного пакета на USB-флешку**.

### 5. 🛡️ Управление локальными политиками паролей
- Просмотр и изменение параметров безопасности через `secedit.exe` и `net.exe accounts`:
  - Минимальная длина пароля (`0–14` символов).
  - Максимальный срок действия пароля.
  - Порог блокировки учетной записи.
  - Включение и отключение требования сложности пароля (`PasswordComplexity`), чтобы при необходимости задать пользователю простой или короткий пароль.
- Готовые профили в один клик: *«Домашний / Сервисный режим»*, *«Стандартная политика Windows»*, *«Корпоративная безопасность»*.

### 6. 📋 Журнал аудита и сводные HTML-отчеты
- Автоматическое журналирование всех действий администратора в `logs/winpass_audit.log`.
- Генерация оформленного **сводного HTML-отчета** по всем учетным записям, Wi-Fi сетям, сохраненным учетным данным и выполненным операциям.

## 🛠️ Инструкция по запуску

### Способ 1: В запущенной ОС Windows (под учетной записью Администратора)
1. Запустите файл **`Run-WinPass.bat`** двойным кликом.
2. Программа автоматически запросит повышение привилегий **UAC (От имени Администратора)** и откроет графическое окно **WinPass Admin Suite**.
3. Либо запустите из консоли PowerShell:
   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\WinPass-GUI.ps1
   ```

### Способ 2: Если пароль единственного администратора забыт (через среду восстановления WinPE / WinRE)
1. Загрузите ПК с установочной флешки Windows / диска восстановления (или удерживайте `Shift` при нажатии «Перезагрузка» на экране входа Windows) и нажмите **`Shift + F10`** для открытия командной строки.
2. Перейдите на флешку с программой и запустите:
   ```cmd
   Start-WinPE.cmd
   ```
3. В меню `Start-WinPE.cmd`:
   - Выберите **`[1]`**, чтобы сразу открыть графический интерфейс `WinPass-GUI.ps1` (в сборках WinPE с поддержкой PowerShell/WPF) и разблокировать учетную запись в реестре `SAM`.
   - Или выберите **`[2]`** (установка перехвата `5x SHIFT` + копирование `WinPass` в `C:\WinPass-Admin`), перезагрузитесь в обычную Windows, на экране входа нажмите **`SHIFT` 5 раз подряд** и в открывшемся окне выполните:
     ```cmd
     C:\WinPass-Admin\Run-WinPass.bat
     ```
   - После сброса пароля нажмите кнопку **«Восстановить оригинальные системные файлы (.bak)»** на вкладке *«4. Режим WinPE и Офлайн-инструменты»*.

## 💿 Готовый загрузочный образ WinPE ISO (Автосборка в GitHub Actions)

В репозитории настроен CI/CD пайплайн **GitHub Actions** (`.github/workflows/build-winpe-iso.yml`), который на облачном раннере `windows-2022` автоматически собирает готовый загрузочный образ **`WinPass-WinPE-amd64.iso`**:

1. Устанавливает официальные пакеты **Windows ADK Deployment Tools** и **Windows PE Add-on**.
2. Монтирует базовый образ `boot.wim` и интегрирует в него пакеты:
   - `WinPE-WMI` и `WinPE-StorageWMI`
   - `WinPE-NetFx` (`.NET Framework 4.x` + `System.Windows.Forms` / `System.Drawing`)
   - `WinPE-Scripting` и `WinPE-PowerShell` (`Windows PowerShell`)
   - `WinPE-DismCmdlets`
3. Встраивает программу **WinPass Admin Suite** в `X:\WinPass\` (внутри RAM-диска `boot.wim`) и дублирует её в корень ISO-диска `\WinPass\`.
4. Настраивает `X:\Windows\System32\startnet.cmd` так, что сразу после загрузки с флешки или диска автоматически открывается графическое окно **`WinPass-WinPE-GUI.ps1`**, где администратор в 1 клик может:
   - **Сбросить пароль любого пользователя в кусте `SAM` на пустой** (обнуление длины NTLM/LM хэша в структуре `V` и снятие блокировки в структуре `F` с автосохранением резервной копии `SAM.winpass.bak`).
   - **Активировать встроенного Администратора (`RID 500`)**.
   - **Установить экранный перехват `5x SHIFT (sethc.exe)`** или **очистить контейнер ПИН-кода Windows Hello (`Ngc`)**.
   - **Прочитать сохраненный пароль автологона (`DefaultPassword`)** из офлайн-куста `SOFTWARE`.
5. Генерирует гибридный загрузочный образ **`WinPass-WinPE-amd64.iso`** (с поддержкой **Legacy BIOS MBR** и **UEFI x64 без нажатия клавиши**) и публикует его в **GitHub Actions Artifacts** и **GitHub Releases**.
